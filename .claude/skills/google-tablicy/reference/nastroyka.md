# Установка моста и починка

Настройка делается **один раз** и работает потом для любой таблицы, к которой у
пользователя есть доступ на редактирование. Занимает минут десять. Ставить на компьютер
ничего не нужно — ни Node.js, ни Python.

Схема целиком:

```
ты  ->  скрипт-мост (tools/gsheets.sh|ps1)  ->  веб-адрес Apps Script  ->  Google Таблица
```

Внутри Google живёт маленькая программа (Apps Script) с собственным веб-адресом. Ты шлёшь
туда JSON с паролем — программа делает, что попросили, и отвечает JSON. Работает от имени
того, кто её установил: может ровно то же, что этот человек умеет руками.

## Как себя вести

**Настройку пользователь делает сам, руками в браузере.** Ты не можешь и не должен заходить
в его аккаунт Google, вводить пароли или нажимать «Разрешить». Твоя роль — диктовать шаги
по одному, ждать «сделал» и помогать, когда пошло не так. Файлы на диске (код скрипта,
файл настроек) создаёшь ты.

**Говори на языке пользователя.** Названия кнопок ниже даны по-русски и по-испански —
подставляй те, что в его интерфейсе.

## Шаг 0. Проверить право на редактирование

Пусть откроет нужную таблицу, впишет что-нибудь в пустую ячейку и отменит (Ctrl+Z, ⌘+Z).

- Получилось — дальше.
- «Только просмотр» / «Solo lectura» — сначала получить у владельца доступ **Редактор /
  Editor**. Без этого идти дальше бессмысленно: мост не может больше, чем сам человек.

## Шаг 1. Создать проект скрипта

1. Открыть **https://script.google.com**
2. Проверить аватар справа вверху: аккаунт тот же, под которым редактируется таблица.
   Это самая частая ошибка — человек залогинен в двух аккаунтах.
3. **Новый проект** / **Nuevo proyecto**.
4. В редакторе лежит заготовка `function myFunction() {}` — выделить всё (Ctrl+A) и удалить.

## Шаг 2. Вставить код

Код лежит в `.claude/skills/google-tablicy/assets/gsheets-webapp.gs`. Попроси открыть этот
файл и скопировать оттуда — надёжнее, чем копировать из чата.

## Шаг 3. Вписать пароль

В самом верху вставленного кода:

```javascript
var TOKEN = 'ВСТАВЬТЕ_СЮДА_ПРИДУМАННЫЙ_ПАРОЛЬ';
```

Между кавычками — длинный пароль, кавычки оставить.

**Менять только эту строку.** Не «заменить всё по файлу»: ниже в коде есть проверка
«пароль вписан», и если заглушка заменится и там, скрипт начнёт сравнивать пароль сам с
собой и на любой запрос отвечать «в скрипте не заменён TOKEN». В версии из `assets/`
проверка уже защищена от этого, но в старых развёртываниях грабли живые.

Пароль **не придумывают из головы и не копируют из инструкций** — его генерируют.
Сгенерируй сам:

Mac / Linux:
```
LC_ALL=C tr -dc 'A-Za-z0-9' < /dev/urandom | head -c 24; echo
```

Windows (PowerShell):
```
powershell -Command "-join ((1..24) | ForEach-Object { ('abcdefghijkmnpqrstuvwxyzABCDEFGHJKLMNPQRSTUVWXYZ23456789').ToCharArray() | Get-Random })"
```

Тот же пароль пойдёт в `.gsheets.json` на шаге 7. Сохранить проект: Ctrl+S.

Ниже есть ещё `var DEFAULT_SPREADSHEET = '';` — можно вписать айди основной таблицы
(из ссылки, между `/d/` и `/edit`), тогда её не придётся указывать в каждом запросе.

## Шаг 4. Назвать проект

Слева вверху «Проект без названия» / «Proyecto sin título» → переименовать, например
`Мост к таблицам` / `Puente a las hojas`. Влияет только на удобство и на текст экрана
с предупреждением в шаге 6.

## Шаг 5. Опубликовать как веб-приложение

1. Справа вверху синяя **Развернуть** / **Implementar** → **Новое развёртывание** /
   **Nueva implementación**.
2. Слева от «Выберите тип» / «Seleccionar tipo» — шестерёнка. Нажать → **Веб-приложение** /
   **Aplicación web**.
3. Заполнить:
   - **Описание / Descripción** — любое, например `версия 1`
   - **Запуск от имени / Ejecutar como** — **Я / Yo (адрес пользователя)**
   - **У кого есть доступ / Quién tiene acceso** — **Все / Cualquier usuario**
4. **Развернуть / Implementar**.

Пункт «Все» обязателен: иначе Google требует вход через браузер и скрипт не достучится.
Защита здесь — пароль из шага 3: без него скрипт отвечает «неверный пароль» и ничего не
делает. Отсюда правило: **адрес и пароль никому не пересылать**, вместе они дают полный
доступ к таблицам аккаунта.

## Шаг 6. Пройти экран с предупреждением

Шаг выглядит пугающе, но он штатный — так выглядит любой свой скрипт, не публиковавшийся
в магазине приложений:

1. **Предоставить доступ / Autorizar acceso** → выбрать свой аккаунт.
2. Экран «**Google не подтвердил это приложение**» / «**Google no ha verificado esta
   aplicación**».
3. Внизу — **Дополнительные настройки / Configuración avanzada**.
4. Затем — **Перейти на страницу «…» (небезопасно)** / **Ir a … (no seguro)**.
5. **Разрешить / Permitir**.

Появится адрес вида:

```
https://script.google.com/macros/s/AKfycb................/exec
```

**Копировать**. Окно не закрывать, пока адрес не перенесён в файл настроек.

## Шаг 7. Сохранить адрес и пароль

Это твоя работа: создай в корне проекта `.gsheets.json` (шаблон — `.gsheets.json.example`):

```json
{
  "url": "адрес из шага 6",
  "token": "пароль из шага 3",
  "tables": {
    "presupuesto": "https://docs.google.com/spreadsheets/d/АЙДИ_ТАБЛИЦЫ/edit"
  }
}
```

`tables` необязателен — это короткие имена для таблиц, с которыми работаете постоянно,
чтобы не искать ссылку каждый раз. Дописывать туда строки можно когда угодно,
переустанавливать ничего не нужно.

`.gsheets.json` уже в `.gitignore`. **Проверь, что он там есть** — в файле лежат ключи от
всех таблиц аккаунта.

## Шаг 8. Скрипт-мост

Уже лежит: `tools/gsheets.sh` (Mac/Linux, нужен `jq` — `brew install jq`) и
`tools/gsheets.ps1` (Windows). Оба делают одно и то же: берут адрес и пароль из
`.gsheets.json`, подставляют пароль в запрос, отправляют, печатают ответ.

`gsheets.ps1` должен лежать в кодировке **UTF-8 с BOM** — иначе Windows PowerShell 5.1
ломает кириллицу внутри скрипта.

## Шаг 9. Проверить

```
bash tools/gsheets.sh ping
powershell -ExecutionPolicy Bypass -File tools\gsheets.ps1 -Ping
```

Ожидаемо: `{ "ok": true, "ping": "скрипт работает", "version": 4 }`

Потом настоящая проверка доступа — список листов:

```
echo '{"action":"listSheets","spreadsheetId":"ССЫЛКА"}' | bash tools/gsheets.sh -
powershell -ExecutionPolicy Bypass -File tools\gsheets.ps1 -Action listSheets -SpreadsheetId "ССЫЛКА"
```

Пришли имена листов — настройка закончена.

## Если правили код скрипта

Изменения **не** применяются сами. Нужно: **Развернуть / Implementar** → **Управление
развёртываниями / Gestionar implementaciones** → карандаш → **Версия: Новая версия /
Nueva versión** → **Развернуть**. Адрес при этом не меняется.

## Что делать, когда сломалось

| Симптом | Причина и лечение |
|---|---|
| `ping` молчит или ошибка сети | Неверный `url` в `.gsheets.json`; развёртывание удалено — сделать новое |
| Приходит HTML вместо JSON | «У кого есть доступ» стоит не «Все» — переразвернуть с правильной настройкой |
| `ping` работает, а любой запрос падает; в ответе HTML «Page Not Found» и код 405 | curl шлёт POST на редирект. В `curl` не должно быть `-X POST` рядом с `-L`: Apps Script отвечает 302 на `script.googleusercontent.com`, и результат забирается оттуда методом GET |
| `неверный пароль` | `token` в `.gsheets.json` не совпадает с `TOKEN` в коде |
| `в скрипте не заменён TOKEN`, хотя пароль вписан | Пароль заменён по всему файлу, включая саму проверку — она сравнивает TOKEN сам с собой. Вернуть в проверке заглушку либо взять свежий `assets/gsheets-webapp.gs` |
| `в скрипте не заменён TOKEN` | Шаг 3 пропущен |
| `не указана таблица` | Ни `spreadsheetId`, ни `table`, ни `DEFAULT_SPREADSHEET` |
| `лист "X" не найден` | Лист переименован — начни с `listSheets` |
| `неизвестное действие` | Опечатка в `action` либо в Google висит старая версия — переразвернуть |
| 404/500 время от времени | Защита Google от потока запросов, не ошибка запроса. В скриптах уже четыре попытки с нарастающей паузой; шли меньше запросов, проверяй итог чтением |
| Правки не видно | Проверь, что развёрнута новая версия, и перечитай диапазон |
| `curl: (56) CONNECT tunnel failed, response 403` | Не Google, а сетевая политика окружения. См. раздел ниже |

## Мост не работает из облачной сессии Claude Code

Если Claude запущен не на компьютере пользователя, а в облаке (claude.ai/code, GitHub
Action), исходящий трафик идёт через прокси с белым списком доменов. По умолчанию
`script.google.com` в него не входит, и `ping` падает с
`curl: (56) CONNECT tunnel failed, response 403`.

Проверить: `curl -sS "$HTTPS_PROXY/__agentproxy/status"` — раздел `recentRelayFailures`.
Обходить запрет нельзя, TLS-проверку отключать нельзя.

Два выхода:

1. **Запускать мост локально.** `tools/gsheets.sh` / `tools/gsheets.ps1` на машине
   пользователя работают без ограничений — так навык и задуман.
2. **Разрешить домены в настройках окружения.** На https://claude.ai/code открыть
   селектор окружений, навести на нужное → значок шестерёнки. В поле **Network access**
   выбрать **Custom**, в **Allowed domains** вписать по домену на строку:

   ```
   script.google.com
   script.googleusercontent.com
   ```

   Оба обязательны: Apps Script отвечает редиректом со второго домена.
   Галочку **Also include default list of common package managers** оставить
   включённой, иначе отвалятся npm, PyPI и прочее. `*.` в начале домена означает
   «любой поддомен». GitHub и MCP-коннекторы через этот список не идут — они ходят
   отдельными путями и не сломаются.

   Изменения подхватывают **новые** сессии, текущая продолжает работать по старой
   политике. Смена списка доменов заодно заставляет заново отработать setup-скрипт.
   Документация: https://code.claude.com/docs/en/cloud-environments#network-access

## Безопасность (проговори пользователю)

- **Адрес веб-приложения плюс пароль = полный доступ ко всем таблицам аккаунта.** Никому не
  пересылать, в git не коммитить, в переписку не вставлять.
- Скрипт работает от имени того, кто его установил. Где человек может править руками — там
  сможет и мост. К чужим таблицам без доступа он не подберётся.
- Пароль утёк — открыть редактор Apps Script, поменять `TOKEN`, переразвернуть новой
  версией, обновить `.gsheets.json`. Адрес не изменится.
- Удаление листа необратимо и требует явного `"confirm": true`. Не подставляй его сам.
