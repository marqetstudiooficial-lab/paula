# Команды моста и правила работы

Запрос — это JSON с полями `action`, адресом таблицы и параметрами. Ответ — JSON, где
`ok: true` либо `ok: false` и `error`. Пароль подставляет скрипт-мост, в файл запроса его
писать не нужно.

Таблица выбирается одним из трёх способов:

| В запросе | Какая таблица берётся |
|---|---|
| ничего не указано | `DEFAULT_SPREADSHEET` из кода скрипта |
| `"spreadsheetId": "https://docs.google.com/spreadsheets/d/.../edit"` | эта (можно и голый айди) |
| `"table": "presupuesto"` | из раздела `tables` в `.gsheets.json` |

Лист — по имени (`"sheet":"Enero"`) или по номеру из ссылки (`"gid":1472095119`).
**Gid не запоминай между сессиями**: пользователь создаёт и удаляет листы. Каждый раз
начинай с `listSheets`.

# ЧТЕНИЕ

| Действие | Что делает |
|---|---|
| `listSheets` | имена листов, gid, размеры, скрытые |
| `read` | значения диапазона (или всего листа) |
| `inspect` | плюс формулы, заливка, цвет и жирность шрифта, объединения, выпадающие списки |
| `condRules` | правила условного форматирования |
| `find` | найти ячейки по значению (до 200 попаданий) |

```json
{"action":"read","sheet":"Presupuesto","range":"A1:H40"}
{"action":"inspect","gid":12345,"range":"E1:J20","backgrounds":true,"formulas":true}
{"action":"find","sheet":"Plan","value":"Мария"}
```

`inspect` отдаёт только то, что попросили флагами (`backgrounds`, `fontColors`,
`fontWeights`, `formulas`, `numberFormats`, `merges`, `validations`), иначе ответ распухает:
диапазон 30×30 — это 900 строк цветов. Бери десятки ячеек, а не тысячи. `"values": false`
выключает значения.

`read` по умолчанию отдаёт значения так, как они видны на экране. `"raw": true` — сырые
(даты числами).

# ЗАПИСЬ ЗНАЧЕНИЙ

| Действие | Что делает |
|---|---|
| `write` | блок ячеек; в ответе `before` — что было до правки |
| `setCell` | одна ячейка (`cell`, `value`) |
| `setFormulas` | формулы; пустая строка — ячейку не трогаем |
| `append` | дописать строки в конец |
| `clear` | очистить: `clearWhat` = `content` (по умолчанию), `format` или `all` |

```json
{"action":"write","sheet":"Presupuesto","range":"B2","values":[["Publicidad",15000],["Producción",8000]]}
{"action":"setFormulas","sheet":"Presupuesto","range":"D2","formulas":[["=SUM(B2:C2)"]]}
{"action":"clear","sheet":"Plan","range":"A10:F20","clearWhat":"content"}
```

`range` в `write` задаёт **левый верхний угол**, размер берётся из `values`: `"range":"B2"`
и массив 2×2 запишут B2:C3.

Поле `before` в ответе — страховка. Записывай его в свои заметки перед тем, как двигаться
дальше: если правка ушла не туда, прежние значения есть и их можно вернуть тем же `write`.

# ОФОРМЛЕНИЕ

| Действие | Что делает |
|---|---|
| `format` | заливка, цвет/жирность/размер шрифта, выравнивание, перенос, границы, формат числа |
| `copyFormat` | скопировать оформление из одного диапазона в другой, в том числе с другого листа |
| `columnWidth` / `rowHeight` | ширина колонок, высота строк |
| `merge` / `unmerge` | объединить и разъединить ячейки |
| `setNotes` | примечания к ячейкам |

```json
{"action":"format","sheet":"Informe","range":"A1:F1","background":"#4a86e8","fontColor":"#ffffff","bold":true,"align":"center"}
{"action":"format","sheet":"Informe","range":"A1:F20","border":{"all":true,"style":"SOLID","color":"#000000"}}
{"action":"format","sheet":"Informe","range":"D2:D40","numberFormat":"#,##0.00 €"}
{"action":"copyFormat","sheet":"Febrero","fromSheet":"Enero","from":"A1:H30","to":"A1:H30"}
{"action":"columnWidth","sheet":"Informe","column":2,"count":3,"width":140}
{"action":"merge","sheet":"Informe","range":"A1:F1","how":"all"}
```

Поля `format`: `background`/`backgrounds`, `fontColor`/`fontColors`, `bold`/`fontWeights`,
`italic`, `fontSize`, `fontFamily`, `align`, `valign`, `numberFormat`, `wrap`, `border`.

Цвета — строкой `#rrggbb`. `"background":"none"` снимает заливку. Множественное число
(`backgrounds`, `fontColors`, `fontWeights`) принимает свой цвет для каждой ячейки массивом
той же формы, что и диапазон.

Границы: `all: true` — рамка снаружи и сетка внутри. Либо по граням: `top`, `bottom`,
`left`, `right`, `vertical`, `horizontal`. Стили: `SOLID`, `SOLID_MEDIUM`, `SOLID_THICK`,
`DOUBLE`, `DASHED`, `DOTTED`.

**Оформление не откатывается** полем `before` — его возвращает только запись значений.
Перед большой переделкой цветов сними снимок: `inspect` с `backgrounds: true` по тому
диапазону, который собираешься менять, и сохрани ответ.

# ВЫПАДАЮЩИЕ СПИСКИ

| Действие | Что делает |
|---|---|
| `inspect` + `"validations": true` | показать, какие значения разрешены |
| `clearValidation` | снять списки с диапазона (значения и оформление остаются) |
| `setValidation` | один общий список: `list` или `fromRange` |
| `setValidationMask` | списки по маске: `true` — список, `false` — ячейка без выпадашки |

```json
{"action":"setValidation","sheet":"Plan","range":"C2:C100","list":["En curso","Hecho","Cancelado"]}
{"action":"setValidation","sheet":"Plan","range":"D2:D100","fromRange":"Referencias!A2:A50","fromSheet":"Referencias"}
{"action":"clearValidation","sheet":"Plan","range":"C2:C100"}
```

`"allowInvalid": true` — список показывается, но чужое значение не блокируется.
`"dropdown": false` — проверка без стрелочки. Размер `mask` в `setValidationMask` должен
точно совпадать с размером диапазона.

# ЛИСТЫ

| Действие | Что делает |
|---|---|
| `addSheet` | создать пустой лист (`name`, `index`) |
| `duplicateSheet` | копия листа со всем оформлением и формулами |
| `renameSheet` | переименовать |
| `deleteSheet` | удалить, требует `"confirm": true` |
| `hideSheet` | скрыть или показать (`"show": true`) |

```json
{"action":"duplicateSheet","sheet":"Enero","name":"Febrero","index":2}
```

`duplicateSheet` — основной приём для «сделай как в прошлом месяце»: копируешь готовый лист
со всем оформлением, потом меняешь в нём данные. Надёжнее, чем собирать оформление заново.

# ПРАВИЛА РАБОТЫ (это важнее списка команд)

**Сначала прочитай, потом пиши.** Никогда не пиши в диапазон, содержимого которого не
видел. Структура таблицы в голове у пользователя не совпадает с тем, что реально в ячейках.

**Ищи людей и строки по названию, а не по номеру строки.** Пользователь вставляет и удаляет
строки по ходу разговора. Номер строки, узнанный десять минут назад, уже может быть чужим.
Перечитывай ключевую колонку перед каждой правкой.

**Проверяй результат чтением.** После правки прочитай тот же диапазон и покажи, что
получилось. `ok: true` означает «запрос дошёл», а не «получилось то, что задумано».

**Показывай, что собираешься сделать, до того как сделал.** Особенно если правок много:
короткая таблица «было → стало» дешевле, чем разбор последствий.

**Не додумывай смысл данных.** Непонятно, что имел в виду пользователь — спроси. Ошибка в
чужой рабочей таблице стоит дороже одного уточняющего вопроса.

**Копи правки, а не сыпь запросами.** Один `write` на блок лучше двадцати `setCell`. Google
не любит поток запросов и начинает отвечать 404 или 500 — это защита от нагрузки, а не
ошибка запроса. В скриптах-мостах встроены четыре попытки с нарастающей паузой, но при
сотнях запросов подряд часть всё равно может не пройти. Отсюда предыдущий пункт: итог
проверяется чтением.

## Грабли, на которых уже обжигались

**Кириллица, испанские буквы и кавычки в командной строке.** Не передавай JSON строкой в
параметре — искажается при передаче через оболочку. Пиши запрос в файл и вызывай скрипт с
путём к файлу. Для простых чтений хватает параметров (`-Action read -Range A1:D10`).

**Строгая проверка данных блокирует запись даже из скрипта.** Если в ячейке выпадающий
список с запретом чужих значений, `write` вернёт «данные не соответствуют правилам
проверки». Лечится `clearValidation` или заменой на общий список.

**Значения списков сверяются посимвольно.** Если у значения в мастер-списке пробел на конце
(«María García »), запись без пробела отобьётся. Бери строки из существующих ячеек листа,
а не набирай руками.

**Цвет бывает важнее текста.** В рабочих таблицах смысл часто закодирован заливкой, а не
словом. Прежде чем считать ячейку пустой, посмотри `inspect` с `backgrounds`.

**Условное форматирование.** Если цвет появляется сам, менять заливку бесполезно — сначала
`condRules`.

**Пересборка большого куска затирает ручные пометки.** Если пользователь что-то подкрасил
или подписал вручную, а ты пересобираешь диапазон целиком, пометки пропадут. Либо правь
точечно, либо сначала выпиши пометки и верни их после.
